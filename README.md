# Celsius Eats - Investment Analysis & Valuation
**Financial Modeling | Capital Budgeting | Valuation**
## Project Overview
This project presents a financial analysis and valuation of **Celsius Eats**, a diversification initiative by Celsius Holdings into the healthy snack food business.
The analysis evaluates the project's financial attractiveness by integrating cost of capital, return on capital, project cash flow, valuation, and investment decision analysis.
## Objective
The objective of this project is to asses the financial implication of the Celsius Eats investment under diffrent business perpectives and determine the conditions under which the project can create value.
## Analysis Framework
The analysis covers:
- Cost of Capital / Hurdle Rate
- Return on Capital (ROC)
- Project Cash Flow Analysis
- 15-Year Finite-Life Valuation
- Longer-Life / Infinite-Life Analysis
- Sensitivity Analysis
- Integrated Investment Decision
